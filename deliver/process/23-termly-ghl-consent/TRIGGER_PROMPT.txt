Put the Brandklout consent standard on a client site, or add a new client to it.

Read 23-termly-ghl-consent.md first. The short version:

Phase 1 (no client input): the GHL consent bridge. Webflow = registered site script
"BrandkloutConsentBridge" (source kit/ghl-consent-bridge.min.js, verify the hosted copy with cmp),
applied in the footer. Instatic = `node consent-kit.mjs instatic apply --only <site> --apply`, then
`instatic publish` (it refuses when someone else's draft is pending). Check with
`node consent-kit.mjs check <page with a GHL form>`.

Phase 2 (after the Termly account exists): Termly script with ?autoBlock=off as the first thing in
the head, above GTM; tag every tracker outside GTM type="text/plain" data-categories="...";
Consent Preferences link in every footer; test before answer / Decline / Accept.

Never publish a site with pending Designer or draft changes. Update the registry table in the
directive when a site changes state.
