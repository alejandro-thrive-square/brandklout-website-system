## Usage

1. Use landing pages as full composition references when building a similar page type.
2. Mix and match - take the hero approach from one page, features from another.
3. Interior pages show common secondary page patterns.
4. All pages demonstrate how sections, tokens, and animations work together.
5. Adapt CSS custom properties to match client tokens before using as a base.
