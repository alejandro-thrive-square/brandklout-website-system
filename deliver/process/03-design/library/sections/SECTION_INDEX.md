## Usage

1. Pick sections that match the wireframe structure.
2. Open the HTML file to preview the pattern in browser.
3. Adapt the CSS custom properties to match client tokens.
4. Compose multiple sections into a full page prototype.
5. Add animations from `../animations/` as needed.
