# Workflow: 06 - QA (Giovanni Serrano)

## Client-Facing Overview
Before launch, we test the staged site across devices, links, forms, SEO basics, performance, and visual accuracy.

## Operational Purpose
Verify the staged Webflow build against quality standards: pixel fidelity, CMS structure, responsiveness, functionality, SEO readiness, and performance.

## Inputs
- Webflow staging URL and build manifest.
- Approved Figma reference (Home + Service template).
- Final content and SEO package.

## Execution Steps
1. Visual fidelity: compare all 4 pages against Figma at 1440px, 1024px, 768px, 375px.
2. Crawl pages for SEO: title tags, meta descriptions, OG tags, H1-H6 hierarchy, alt text.
3. Test functionality:
   - Navigation links (including anchor links: #services, #about, #portfolio, #sample, #reviews, #contact)
   - Contact forms on all 4 pages with correct goal options
   - FAQ accordion on Invest page
   - CMS collection bindings (Testimonials placeholder)
4. Performance: Lighthouse audit, image optimization, lazy loading.
5. Cross-browser: Chrome, Safari, Firefox, Edge.
6. Triage defects — block launch until critical/high issues resolved.
