# Workflow: 08 - QA (Giovanni Serrano)

## Client-Facing Overview
Before launch, we test the staged site across devices, links, forms, SEO basics, performance, and visual accuracy.

> [!IMPORTANT]
> **Integrity Rule**: Any change to the Python executor or technical logic of this workflow must be documented here immediately.

## Operational Purpose
Verify Giovanni's staged Webflow build against the approved final design, 4-page scope, CMS structure, responsiveness, functionality, SEO readiness, accessibility, and performance.

## Inputs From Sales / Previous Phase
- Webflow staging URL and build manifest from `07-webflow-build`
- Approved final design package from `05-design-revisions`
- Final content and SEO package from `06-content-seo`

## Execution Steps
1. Compare staging templates against the approved final design across breakpoints.
2. Crawl all approved pages for metadata, headings, links, schema, and alt text.
3. Test forms, CTAs, navigation, CMS edge cases, analytics, and responsive behavior.
4. Triage defects and block launch until critical/high issues are resolved.
