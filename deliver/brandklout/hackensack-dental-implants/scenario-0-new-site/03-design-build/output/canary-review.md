# hackensack-dental-implants · home page canary

Rebuilt 2026-09-30 to **the style the client chose**: concept 04, "Human Transformation",
https://hackensack-dental-implants.webflow.io/concept-04-human-transformation. The first canary of
the same day (commit `1ef53236`) was designed before that choice was known and is replaced.

Local build only. Nothing is pushed to Instatic or Webflow and the live site is untouched.

## How to open it

- **Double-click `OPEN-home.html`** in this folder. It is generated by the build and points at the
  built files with relative paths, so it works straight from the file system.
- Or run `node code/serve.mjs` from this folder and open http://127.0.0.1:4173/. The server only
  answers while that command is running.
- `code/site-src/dist/index.html` is the file that gets pushed. It uses root-relative paths
  (`/assets/…`), so opened by double-click it shows unstyled; that is expected.

## How close it is

The concept is one self-contained page (its own stylesheet and markup inside a Webflow embed), so
the build was made from its values, not from a reading of a screenshot: same section order, same
copy, same grid ratios, paddings, radii, colours and typefaces (Newsreader and DM Sans).
Side-by-side strips, concept on the left and build on the right, are in `look/compare-1440/` and
`look/compare-390/` (`python code/compare.py 1440` regenerates them).

## Motion

The concept reveals sections as they enter and drifts its images. That is kept. Added, without
moving anything: the patient's sentence is written word by word while the story block holds; the
four steps light up in order while the process block holds; and scroll wipes each gallery tile from
before to after while the gallery holds. On tablets and phones nothing is pinned and the same three
are scrubbed by position. If the client wants the concept's motion and no more, the three pins come
out with one block in `js/00-runtime.js`.
