The site

What this site does, and what it does not do yet.

The statement that used to be here described an accessibility widget this site does not have. This one describes what is actually true, which is more useful and rather less impressive.

Tell us about a problem What it does
HomeAccessibility statement

What It Does

Six things built into every page.

Semantic markup

Real headings in order, real lists, real tables, and one main landmark per page, so a screen reader can move through a page by structure rather than by guessing.

A skip link

The first thing on every page is a link to the main content, so a keyboard user does not tab through the whole menu on each one.

Text alternatives

Every photograph carries alt text describing the frame, and decorative marks are hidden from assistive technology rather than announced.

Keyboard operation

Menus, accordions and the mobile drawer work from the keyboard, with a visible focus outline that is not removed.

Legible type

Nothing on a phone is set below the label floor, the type scales with the viewport rather than being fixed in pixels, and text can be zoomed without the layout breaking.

Reduced motion

The scroll animations respect the operating system’s reduce-motion setting, and the page is complete and readable with every animation off.

What It Does Not

Three honest limitations.

No accessibility overlay

There is no widget, no screen-reader mode and no font-size toolbar. Overlays of that kind are widely held to make things worse, so the work has gone into the pages instead.

The embedded map

The Google Map on the contact page is a third-party embed and we do not control its accessibility. The address and directions are given as text beside it for that reason.

No formal audit yet

The site is built to WCAG 2.1 AA as a target and has not yet been independently audited against it. We will say so here when it has.

If a page will not work for you

Call the practice and we will give you whatever is on that page over the phone, and then fix the page.
