### The media purge mistake (seq 32–33), so nobody repeats it

After seq 31 a throwaway `.tmp/prune-media.mjs` was meant to remove the three assets no page used
any more. It read `media-map.json` as a flat map (it is `{ base, uploadedAt, map }`), so "used"
came out empty and it purged ALL 19 library files. Caught minutes later by the missing
guarantee photo: `upload-media` re-uploaded the 19 (new ids), `build-import-input` → `ship` →
`push-site` (seq 32; one SEO cell PATCH hit a transient 502) → re-push (seq 33, all 30 ok) →
publish. `verify-live` then FAIL none on 205 asset references. The script now refuses on a map
with no `.map` and reports `library 19 used 19 unreferenced []`. Lesson: a delete script gets a
dry run that PRINTS the list, and `tail` never hides it.
