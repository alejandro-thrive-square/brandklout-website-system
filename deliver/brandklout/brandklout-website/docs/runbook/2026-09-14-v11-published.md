### Found and fixed on the way

1. **`frame-src 'none'` on 31 of 32 pages.** Every in-place story player and the video pop-up were
   blocked. v11 creates its iframes in script, and `autoTrust` only opens pages with a static embed.
   Fixed with `frameOrigins`, written read-merge-write so `siteScripts` survived.
2. `OPEN-ME.html` was read as a page, and the v2 survey overlay forced the v2 path. Now a
   not-pages list and `retired-v2/`.
3. The duplicate `revenue-attribution` page would have published a second "Lead to Collection" title.
   It is now an alias.
4. **Instatic's reset stylesheet took away Sang's browser defaults.** The first live `visual-diff`
   showed every page 12–17px shorter at 1440 and 26–27px at 390, and `dental-implant-marketing`,
   `guarantee` and `hipaa` 58–84px shorter, with bands down whole pages. The cause is
   `reset-*.css`'s `:where(*) { margin: 0; padding: 0 }`, plus block-level `img` and `svg`, bare
   buttons and inherited link colours. `instatic-reset-revert.css`, prepended to the code asset,
   reverts each rule at the same zero specificity.
5. Plugin settings were preserved even though the obvious tool (`set-origins.mjs`) would have PUT only
   three keys.
7. **Six specialty pages published their hero illustration as `<img src="#" alt="">`.** Instatic's
   importer drops a `data:` URI image entirely (src, alt, size). The six were inline SVG placeholders
   with no online original (general dentistry, multi-location, oral surgery, orthodontics,
   periodontics, prosthodontics). prepare-source now decodes every `data:` image into an
   `inline-<hash>.svg` file that goes through upload-media and set-alt like any other image.
   Found by the widget-blocked `visual-diff`: every other page was at ≤0.35%, and these six were at 3–5%.
6. A false alarm, recorded so nobody repeats it: a grep for `@font-face{` found no font rules on the
   live pages, and a second set was generated into the code asset (seq 15). They were already in
   Instatic's `framework-*.css`, and CDP `getPlatformFontsForNode` shows Manrope and DM Sans rendering
   as web fonts on both sides; the installed files are byte-identical to Google's. The duplicates were
   removed. `verify-live` now checks every quoted family has an `@font-face` across all the page's
   stylesheets.

### The accessibility widget changes every page (not ours; decide whether to keep it)

The plugin's `siteScripts` loads **sienna-accessibility** from cdn.jsdelivr.net on every page. That
is the floating button bottom-left. Nothing in this repo added it, and it predates this run. At load
it writes an inline `font-size` onto every text element, **rounded down**. On
`/ai-search-authority`, 65 elements changed: the 64.8px `<h1>` becomes 64px
(`data-asw-org-font-size=64`). Blocked, the page matches the build exactly (`<h1>` 64.8px, no inline
sizes). The effect is a sub-pixel-to-1px shift of viewport-sized text, which is imperceptible but on every
page. It also means every visitor downloads and runs a third-party script. `visual-diff` and
`compare-live` now block it (so they measure the import); `KEEP_WIDGET=1` keeps it.

### Gotchas

- **v11's CSS is not in the style registry.** It is the code asset `src/styles/site.css`, so the
  Styles panel is empty. Edit Sang's package (or `agency/site.css`) and rebuild; do not edit the
  asset in the admin, because the next push overwrites it.
- `push-site.mjs --apply --force` replaces every page. Sang edits in the admin (see above): diff the
  live pages against `.tmp/import-out.json` first (node ids are shared), as this run did.
- Plugin settings: never use `deliver/process/18-instatic-embeds/set-origins.mjs` on this instance.
  It PUTs only the three origin keys. Use a read-merge-write like `set-frame-origins.mjs`.
- `visual-diff --source` and a live `visual-diff` at the SAME width write the same `-local.png`
  files; different widths can run together.
- A live-vs-local text difference at identical page height is the accessibility widget first
  (above), not fonts: Instatic's `@font-face` rules live in `framework-*.css`. Ask CDP
  (`CSS.getPlatformFontsForNode`) before theorising.
