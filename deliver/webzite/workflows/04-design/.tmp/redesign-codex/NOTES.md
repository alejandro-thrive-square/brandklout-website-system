# Notes

- One idea: the homepage is a profit ledger, using the equation as the page's structural system instead of a decorative headline.
- Key motion: full-page dark field switches, editorial reveal blocks, service media swaps on hover/focus, word-fill proof copy, count-up stats, controllable capability marquee, and a lightweight cursor response.
- Removed: the old ambient particle canvas, texture overlay, and fragile manual 300svh pinned hero choreography.
- Constraint stance: Inter + JetBrains Mono only, dark Webzite palette only, yellow as the primary emphasis/action color, accurate proof, testimonials, and canonical $400/page / 2 working days/page pricing.
- Biggest risk: the design is intentionally more editorial and sparse than a conventional service homepage, so the award-site quality depends on animation timing and viewport-scale composition being preserved in implementation.
