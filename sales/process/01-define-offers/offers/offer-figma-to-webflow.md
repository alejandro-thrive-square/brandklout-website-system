# Offer: Figma to Webflow Development

## 1. Overview
This offer applies when a client already has a completed Figma design and needs it built in Webflow. No design work is required. The deliverable is a fully developed, responsive Webflow website that matches the Figma file pixel-for-pixel.

## 2. Client Profile
- Has a finished Figma design file (desktop at minimum, ideally with mobile/tablet breakpoints).
- May or may not have a design system or component library in Figma.
- Looking specifically for a Webflow developer, not a designer.
- Typical Upwork keywords: "Figma to Webflow", "convert design to Webflow", "Webflow developer needed", "PSD/Figma to Webflow".

## 3. Scope of Work

### Phase 1: Design Review & Planning
- Review the Figma file for completeness: all pages, states, responsive breakpoints.
- Flag any missing elements (hover states, mobile layouts, error states, loading states).
- Define the CMS structure if the design includes dynamic content.
- Agree on interaction/animation specifications (what moves, what scrolls, what triggers).

### Phase 2: Webflow Development
- Pixel-perfect Webflow build from the approved Figma designs.
- Clean, semantic class naming following a consistent methodology.
- Responsive implementation across all breakpoints (desktop, tablet landscape, tablet, mobile landscape, mobile).
- CMS collections setup and template pages for dynamic content.
- Webflow native interactions and GSAP animations as specified.
- Forms with proper validation and submission handling.
- Third-party integrations as specified (Calendly, Mailchimp, analytics, etc.).

### Phase 3: QA & Launch
- Cross-browser testing (Chrome, Safari, Firefox, Edge).
- Design fidelity check: overlay comparison between Figma and live build.
- Performance optimization (image compression, lazy loading, clean code output).
- SEO foundation: meta titles, descriptions, Open Graph tags, alt text.
- Client walkthrough of the Webflow Editor.
- Domain connection and launch.

## 4. What the Client Needs to Provide
- Complete Figma file with view/edit access.
- All assets exported or available in the Figma file (icons, images, fonts).
- Final copy embedded in the Figma file or in a separate document.
- Interaction/animation references or descriptions if not annotated in Figma.
- Access to domain registrar for DNS configuration.

## 5. Pricing Model
- **$200 / page development.** No design line item — the client provides the Figma file.
- Canonical rates and formulas: [PRICING_TIMELINE_RULES.md](../../../PRICING_TIMELINE_RULES.md).
- Custom interactions (GSAP-heavy, scroll-driven animations) and integrations beyond standard wiring are quoted as add-ons.

## 6. Timeline Estimate
- **Duration = pages × 1 day** (development only).
- Examples: 5-page site = 5 days; 8-page site = 8 days.
- See [PRICING_TIMELINE_RULES.md](../../../PRICING_TIMELINE_RULES.md) for the canonical rule.

## 7. Differentiators
- Pixel-perfect execution. The live site matches the Figma design exactly.
- Clean Webflow structure that is easy to maintain and scale.
- Webflow Editor training so the client or their team can update content independently.
- Experience working directly from Figma with proper use of auto-layout, components, and design tokens.
- No design opinions injected. The build respects the designer's decisions.

## 8. Risks & Mitigations
| Risk | Mitigation |
| :--- | :--- |
| Incomplete Figma file (missing pages, states, or breakpoints) | Design Review phase catches gaps before development starts. Flag and resolve upfront. |
| Fonts not available or not licensed for web | Confirm font licensing during review. Suggest alternatives if needed. |
| Overly complex animations not feasible in Webflow | Assess during planning. Propose GSAP solutions or simplify where necessary. |
| Client expects design changes during development | Contract clearly states this is a development-only engagement. Design changes quoted separately. |
