# MCP Profile: Prospect Audit

Use this profile for pre-contract Sales and Growth work on public prospect websites, public job posts, public listings, public competitor pages, and public reference material.

## Allowed Use

- Capture public pages, screenshots, page text, metadata, SEO observations, accessibility observations, and design notes.
- Create public-site audit reports and redesign inputs.
- Store outputs in the active workflow's `.tmp/` folder.

## Required Checks

- Use public URLs and public source material by default.
- Do not use private logins, private sessions, cookies, gated pages, or client credentials unless the user explicitly confirms that access in the current workflow.
- Respect workflow-specific rate limits and attribution requirements.

## Confirmation Required

Sending outreach, emailing prospects, submitting forms, using private session data, scraping gated/private content, or deploying public-facing prospect material requires explicit confirmation unless the workflow directive already grants that action.

## Version Control

This profile follows the root-level version control rules in [SYSTEM_RULES.md](../../SYSTEM_RULES.md). Do not commit secrets, OAuth tokens, API keys, passwords, private cookies, or binary/media assets.
